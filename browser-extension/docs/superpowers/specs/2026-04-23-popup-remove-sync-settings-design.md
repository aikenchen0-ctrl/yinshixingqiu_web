# 插件弹窗移除同步配置设计

## 目标

将浏览器插件弹窗中的“同步配置”整块内容完全删除，不再展示接口地址输入框和保存配置按钮。

## 范围

- 删除弹窗入口对同步配置组件的渲染。
- 删除仅供该 UI 使用的本地状态、保存逻辑与相关导入。
- 删除未再被引用的 `SettingsForm` 组件文件。

## 非目标

- 不修改后台同步主流程。
- 不删除底层 `apiBaseUrl` 存储结构和相关服务代码。
- 不调整文章预览、同步按钮、结果面板行为。

## 方案

采用最小改动方案，只移除弹窗展示层。这样可以满足“同步配置这一块全部删除”的需求，同时避免把后台同步能力和后续配置来源一并破坏。

## 验证

- 检查项目内不再存在弹窗对 `SettingsForm` 的引用。
- 检查页面文案中不再出现“同步配置”“保存配置”。
- 运行测试与构建，确认插件仍可编译。
